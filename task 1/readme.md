# Task 1: Text Generation - Generative AI Internship

## 1. Project Title and Objective

* **Project Title:** Generative AI Internship Task 1 - Text Generation
* **Objective:** Explore, generate, and evaluate text outputs for 20 structured educational and technical prompts using conversational Generative AI tools and programmatic inference APIs.

## 2. Overview of the 20 Samples

This project contains 20 text-generation prompts across multiple domain areas:

1. **Artificial Intelligence Fundamentals:** Core definitions, mechanisms, and real-world examples.
2. **Technology in Education:** Analysis of modern digital learning transformations.
3. **Creative Storytelling:** Narrative on an engineering student learning with AI.
4. **AI for Engineering Students:** Practical applications, debugging, and revision workflows.
5. **AI vs Machine Learning vs Deep Learning:** Definitions, differences, and practical examples.
6. **Innovative AI Project Ideas:** Five beginner-friendly project concepts with incremental strategies.
7. **Learning Programming:** Educational guidance on consistency vs. memorization.
8. **How AI Chatbots Work:** High-level pipeline explanation of LLM processing.
9. **Online Learning vs Traditional Learning:** Detailed comparison matrix and trade-offs.
10. **The Future of Education:** Speculative essay set in 2040.
11. **Cybersecurity Awareness:** Definitions, threats, and a student checklist.
12. **Responsible AI Usage:** Academic integrity and fact-checking principles.
13. **Human Teachers vs AI Assistants:** Comparative evaluation of human vs. AI roles.
14. **Student and AI Assistant Dialogue:** Multi-turn roleplay explaining Python loops.
15. **Robotics in Everyday Life:** Applications across healthcare, manufacturing, and agriculture.
16. **Solving Programming Difficulties:** Troubleshooting learning bottlenecks for beginners.
17. **Seven-Day Study Plan:** Structured schedule balancing Python learning and exam prep.
18. **Limitations of AI Models:** Examination of hallucinations, cutoffs, and verification strategies.
19. **Emerging Educational Technologies:** Analysis and impact ranking of 5 technologies.
20. **Dependence on Artificial Intelligence:** Analysis of cognitive offloading risks.

## 3. How Samples Were Generated

The 20 responses in the `generated_samples/` directory were manually generated by entering each prompt directly into the interactive Google Gemini web interface (`gemini.google.com`) and saving the raw outputs as individual plain-text `.txt` files.

## 4. Model Version Verification

To verify the specific model version used during manual web interface generation:

1. Open your chat session at `gemini.google.com`.
2. Look at the top selector or bottom metadata of the conversation window to check the active tier (e.g., *Gemini 1.5 Flash*, *Gemini 1.5 Pro*, *Gemini 2.0*, etc.).
3. If using the programmatic API script, the exact model version is declared explicitly in the code via the model string (e.g., `gemini-1.5-flash`).

## 6. Instructions for Running the Inference Demonstration

### Prerequisites

* Python 3.9 or higher installed on your system.
* A valid Gemini API Key from [Google AI Studio](https://aistudio.google.com/).

### Setup & Execution

1. **Clone or Download Project Repository:**
```bash
git clone <repository_url>
cd <repository_folder>

```


2. **Install Required Packages:**
```bash
pip install google-generativeai

```


3. **Configure API Key:**
Set your Google Gemini API key as an environment variable:
* **Linux/macOS:**
```bash
export GEMINI_API_KEY="your_api_key_here"

```


* **Windows (Command Prompt):**
```cmd
set GEMINI_API_KEY=your_api_key_here

```


* **Windows (PowerShell):**
```powershell
$env:GEMINI_API_KEY="your_api_key_here"

```




4. **Run the Script:**
```bash
python main.py

```


*(If using a Jupyter Notebook, open `inference_demo.ipynb` and run all cells sequentially).*
