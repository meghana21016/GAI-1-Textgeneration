## 1. Weekly Overview & Daily Schedule Structure

To effectively learn Python while preparing for university examinations, this plan uses **interleaved learning**—combining technical coding sessions with core academic revision every single day.

### Daily Time Block Allocation (4–5 Hours Total)

* **Block 1 (Morning / Early Afternoon):** 90 mins — Exam Revision (High-Focus Theory)
* **Block 2 (Late Afternoon):** 90 mins — Python Fundamentals & Hands-on Coding
* **Block 3 (Evening):** 60 mins — Review, Active Recall & Practice Problems
* **Breaks:** 10–15 min breaks between blocks; 8 hours of sleep reserved nightly.

## 4. Measurable Progress Goals

By the end of Day 7, the student will evaluate their progress using these concrete benchmarks:

1. **Academic Readiness Check:** Successfully complete 3 past exam papers (Math, Physics, Electrical) achieving a target score of **80% or higher** without referring to solution sheets.
2. **Coding Autonomy Test:** Write a 50+ line Python script utilizing loops, functions, lists, and dictionaries **from scratch** without looking at video tutorials.
3. **Debugging Benchmark:** Identify and fix 5 deliberate syntax and logic errors in a provided test script within 20 minutes.
4. **Consistency Metric:** Complete 100% of the daily scheduled 90-minute revision blocks without burning out or sacrificing sleep.
